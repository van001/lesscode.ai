
# Karma Protocol RFC v0.1

## Semantic Runtime Protocol

Core grammar:

```text
actor + intent + noun
```

Examples:

```text
client + request + appointment
doctor + approve + refill
manager + publish + feed
```

Karma defines:
- workflows
- ACLs
- schemas
- ownership
- state transitions
- effects
- business meaning

REST models resources.
GraphQL models data shape.
Karma models business meaning.
